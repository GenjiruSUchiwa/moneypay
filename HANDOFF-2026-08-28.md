## Travail accompli (committé & poussé, branche `main`)

- `5a5bc3e` — **Refonte des trois feuilles Recharger / Convertir / Envoyer**
  (réf. Mobbin : Revolut « Add money »/« Move money », Wise « Send money » — flux consultés via
  le MCP Mobbin, l'utilisateur avait fourni 3 URL Mobbin de départ : Revolut, Wise, Family).
  - **Convertir** : pile `.fx-stack` de deux cartes `.fx-card` (FCFA → USD) avec pastille
    `.fx-mid` sur la couture, curseur clignotant `.fx-caret`, pastille de taux effectif
    (« 1 $ = 628 F, marge incluse »), montant USD en `--credit`, état solde insuffisant
    (montant rouge + message chiffré + CTA désactivé). NOUVELLE étape `confirm`
    (`convertToConfirm`/`convertBackAmount`/`convertConfirm`) ; la conversion **débite
    S.balance** et pousse une tx `kind:"conversion"` (label déjà présent dans `KIND_LABELS`).
  - **Recharger** : ligne méthode → carte `.method-card` (aplat `--well`, logo + « Changer »),
    presets conservés ; confirm/done inchangés sur le fond, animés.
  - **Envoyer** : rangée « Récents » `.recents`/`.recent` (4 premiers contacts, masquée si
    recherche), avatars teintés `contactAvatar()` (couleur stable par index via `AV_TINTS`
    = tokens `--cat-*`), liste « Tous les contacts », et écran de succès avec **chronologie
    `.tl`/`.tl-row` façon Wise** (3 jalons en cascade, delays .35/.55/.75 s) + bouton
    « Partager le reçu ».
  - **Animations transverses** : `.flow.fwd/.back` (glissement d'étape, réutilise les
    keyframes `stepFwd`/`stepBack` du parcours carte), `.bump`/`digitPop` (pulsation du
    montant à chaque frappe), `.receipt` (riseIn du reçu). ⚠ Mécanique clé : `F.dir` et
    `F.bump` sont **consommés au rendu** (`flowWrap()`, `consumeBump()`) pour ne jouer
    qu'une fois — les actions les posent, le rendu les efface. Ne pas « corriger » ça.
  - CSS : l'ancien bloc `.fx-leg`/`.fx-swap` a été SUPPRIMÉ et remplacé ; `.fl-flag` est
    devenu global (plus scopé à fx-leg — profite aussi à `countriesSheet`).
